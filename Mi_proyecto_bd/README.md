# Proyecto Base de Datos - Actividad 2

Este proyecto es una demostración práctica del uso de Git, GitHub y Visual Studio Code para la asignatura de **Base de Datos** del **Centro Educativo Nonogasta (CEN)**.

## Archivos del Proyecto
- `schema.sql`: Estructura SQL con las tablas `estudiantes` y `cursos`.
- `README.md`: Documentación e informe del trabajo.

## Cómo hicimos el video

### Herramientas utilizadas
- **Editor de código:** Visual Studio Code (con la terminal integrada).
- **Control de versiones:** Git.
- **Plataforma remota:** GitHub.
- **Grabación y Edición:** OBS Studio y Edits.
